# Picture packs: keep this folder empty

This repo is public, so pictures don't go here. They live in the private repo
`hogfanboy/pocket-jumbotron-content` (same layout). GitHub Actions checks it out and runs
`tools/build-packs.mjs` to publish the packs that screens download from their web page
("Get the latest Pocket Jumbotron pictures"). The layout is described in that repo's README.

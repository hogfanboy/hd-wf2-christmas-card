# HD-WF2 LED Christmas Card

Custom firmware for the Huidu HD-WF2 (ESP32-S3) LED Christmas cards (128x64 HUB75 panel). It replaces the stock Huidu firmware to give much better color and lets the cards update themselves over WiFi from this repo.

# Pocket Jumbotron

Replacement firmware and website for Huidu HD-WF2 LED cards (ESP32-S3, 128x64 HUB75 panel). It gives the panel
full color, plays your own pictures, videos, text, clocks, countdowns, weather and effects, and updates itself
over WiFi.

- Website and phone app: https://hogfanboy.github.io/hd-wf2-christmas-card/
- Install (Chrome or Edge on a computer, USB cable): https://hogfanboy.github.io/hd-wf2-christmas-card/install.html

How it works and what is verified: [PROJECT-NOTES.md](PROJECT-NOTES.md).
